이 방침은 파닥 스도쿠 앱과 이 안내 웹사이트에 적용됩니다. 앱 운영 및 개인정보 문의 담당은 파닥 스도쿠 개발자이며 연락처는 devfadakworld@gmail.com입니다. 별도의 앱 회원가입은 없습니다. Android 정식 패키지는 com.fadak.sudoku이며 테스트 패키지는 com.fadak.sudoku.dev입니다.

현재 배포 상태

현재 제공하는 기본 테스트 APK는 인터넷 권한과 광고·결제 SDK가 없는 오프라인 버전입니다. 아래의 광고·구매 검증 내용은 해당 기능을 포함하는 버전에만 적용됩니다. 상용 구매 서버의 운영사·보관 국가가 확정되기 전에는 그 서버를 사용하는 정식 버전을 공개하지 않으며, 활성화 전에 이 방침을 갱신합니다.

1. 기기에 보관하는 게임 데이터

퍼즐 진행, 숫자와 메모, 표시, 실행 취소 이력, 북마크, 완료 기록, 일일 도전과 학습 진도, 언어와 화면 설정을 기기에 저장합니다. 이는 이어하기와 개인 기록 제공에 사용하며 개발자 서버로 전송하지 않습니다. 별도의 행동 분석 SDK를 사용하지 않습니다.

앱은 연락처·카메라·마이크·정확한 위치 권한을 요청하지 않습니다. 게임 데이터는 사용자가 앱 데이터를 지우거나 앱을 삭제할 때 기기에서 삭제됩니다. 완료 기록만 지우는 기능은 다른 게임 진행을 삭제하지 않습니다.

2. 직접 선택하는 백업과 외부 링크

백업을 내보내거나 가져올 때 Android 파일 선택기에서 사용자가 고른 파일만 읽거나 씁니다. 백업에는 게임 진행과 설정이 포함되며 구매 토큰이나 구매 권한은 포함되지 않습니다. 파일은 암호화되지 않은 JSON이므로 보관·공유할 위치를 신중히 선택해 주세요. 개발자가 백업을 자동으로 업로드하지 않습니다.

클라우드 드라이브를 파일 보관 위치로 선택하면 해당 제공자의 정책이 적용됩니다. 앱 삭제로 외부에 저장한 백업 파일까지 지워지지는 않으므로 별도로 삭제해 주세요. 학습 출처나 개인정보 안내 링크를 열면 외부 브라우저와 해당 웹사이트의 정책이 적용됩니다.

3. 광고가 포함된 버전

광고가 포함된 버전은 Google AdMob과 Google의 동의 관리 도구를 사용합니다. 필요한 동의나 선택 절차를 제공하며, 설정의 개인정보 선택에서 지원되는 선택을 다시 관리할 수 있습니다. 구매 확인·복원 대기 중이거나 광고 허용 정책을 확인하지 못한 상태에서는 광고를 요청하지 않습니다.

Google 광고 SDK는 광고 제공·측정·부정행위 방지를 위해 IP 주소와 이를 통한 대략적인 위치, 광고 및 앱 상호작용, 성능·진단 정보, 광고 ID 등 기기·계정 식별자를 처리할 수 있습니다. 비개인화 광고도 광고 전달·보안에 필요한 데이터를 처리할 수 있습니다. 구체적인 처리와 보존은 Google의 정책 및 적용되는 동의 선택에 따릅니다. Google 개인정보처리방침, 광고 SDK 데이터 안내를 참고해 주세요.

4. Google Play 결제와 구매 검증

결제 기능이 포함된 버전에서는 Google Play가 결제와 결제 계정을 처리합니다. 개발자는 카드 번호나 결제 수단의 전체 정보를 받지 않습니다. 광고 제거 권한 확인·복원·환불 반영을 위해 구매 토큰, 앱 패키지 ID, 상품 ID, 구매 검증 상태, 구매 승인 처리 여부, 검증 시각을 최소 구매 검증 서버에서 처리합니다.

서버는 구매 토큰을 암호화하여 보관하며 토큰의 SHA-256 해시를 지원용 구매 확인 번호로 사용합니다. 서버 원장에는 게임 보드·메모, Google 계정 이메일, 광고 ID, 카드 번호를 저장하지 않습니다. 구매 토큰은 Google Play Developer API를 통해 검증합니다. 정상 구매 기록은 구매 권한 유지와 복원에 필요한 동안 보관하고, 취소·환불이 확인된 기록은 최종 확인 후 90일이 지나면 삭제하도록 구성합니다. 구매 확인 번호와 함께 이메일로 삭제를 요청할 수 있습니다.

요청의 IP 주소는 서버의 과도한 요청 방지에 잠시 사용되며 앱 서버는 요청 본문·구매 토큰·IP를 일반 로그에 기록하지 않습니다. 운영 호스팅 업체와 국가, 프록시 로그 및 보관 설정은 실제 서비스 배포 전에 이 방침에 추가합니다. 기존에 확인한 광고 제거 권한은 단순 네트워크 장애만으로 취소하지 않습니다.

5. 지원 문의

이메일로 문의하면 발신 이메일 주소, 문의 내용, 사용자가 직접 첨부한 화면이나 진단 정보를 문제 해결과 답변에 사용합니다. 진단 정보 복사는 전송이 아니며 사용자가 내용을 확인해 직접 보낼 수 있습니다. 비밀번호·카드 번호·전체 구매 토큰을 보내지 마세요. 첨부한 백업에는 게임 기록이 포함될 수 있습니다.

문의 메일은 Gmail을 통해 처리됩니다. 해결된 문의는 원칙적으로 마지막 답변 후 90일 안에 삭제하며, 진행 중인 분쟁이나 법률상 보존 의무가 있는 경우 필요한 범위에서 더 보관할 수 있습니다. 보존이 필요한 사유와 기간은 요청 시 안내합니다.

6. 이 웹사이트와 국외 처리

이 사이트는 GitHub Pages에 게시됩니다. 개발자가 별도의 광고·방문 분석 스크립트나 추적 쿠키를 추가하지 않습니다. GitHub는 사이트 제공과 보안 등을 위해 방문자의 IP 주소 등 기술 정보를 처리할 수 있습니다. GitHub 개인정보처리방침이 적용됩니다.

Google 및 GitHub의 서비스는 사용자가 거주하는 국가 밖에서 정보를 처리할 수 있습니다. 해당 사업자와 처리 위치·보호 조치·보존에 대한 내용은 각각의 공개 정책을 확인해 주세요. 구매 검증 서버에 대한 구체적인 국외 이전 정보가 필요한 경우에는 서버 운영 장소를 정한 뒤 공개 전에 고지합니다.

7. 선택과 권리 행사

앱 회원 계정이 없으므로 별도의 회원 탈퇴는 없습니다. 기기 안의 데이터는 Android 앱 정보의 저장공간 메뉴에서 지울 수 있습니다. 이는 되돌릴 수 없으므로 필요한 백업을 먼저 내보내세요. 외부 백업은 직접 삭제해야 합니다.

개발자가 보유한 문의·구매 검증 정보에 대한 열람·정정·삭제·처리 제한 등 적용되는 권리는 이메일로 요청할 수 있습니다. 필요한 최소 정보로 요청자를 확인하며 관련 법에 따라 처리합니다. 법률상 보존이나 구매 분쟁 때문에 즉시 삭제할 수 없는 경우 사유를 설명합니다. 권한 확인 기록을 삭제하면 이후 복원 시 Google Play를 통한 재검증이 필요할 수 있으며, 데이터 삭제 요청 자체가 구매 환불은 아닙니다.

8. 아동과 방침 변경

앱은 일반 이용자를 위한 퍼즐 게임이며 아동을 대상으로 개인정보 제공을 유도하지 않습니다. 보호자가 아동의 정보가 문의나 다른 경로로 전달되었다고 판단하면 연락해 주세요. 광고를 포함하는 버전의 대상 연령과 지역에 맞는 설정은 공개 전에 검수합니다.

수집 항목·목적·보관 방식 또는 서비스 제공자가 바뀌면 이 페이지의 수정일과 내용을 갱신하고, 필요한 경우 앱 내 안내 또는 동의 절차를 제공합니다. 중요한 변경은 적용 전에 안내합니다.
